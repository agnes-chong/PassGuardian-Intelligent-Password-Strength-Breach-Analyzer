# 🔐 PassGuardian: Password Strength & Breach Analyzer

**Objective:**  
This project evaluates password strength using entropy, pattern analysis, and breach detection via the *Have I Been Pwned* API.  

**Algorithms used:**  
- Entropy Calculation (Information Theory)  
- zxcvbn Heuristic Scoring  
- K-Anonymity (SHA-1 + HIBP API)  
- Optional Random Secure Password Generation  

**Tools:**  
Python, Jupyter Notebook, zxcvbn, requests, hashlib
